По клиентам · 30 дней

По этапам

Этапы считаются по смене статусов, которую дашборд видит с момента запуска. Первые данные появятся через сутки.

Отгружены без «Отгрузки FBS»

Галочку «Отгрузка FBS» сотрудник ставит на экране отгрузки. Без неё услуга не попадёт в счёт клиенту. Заказ проверяется ещё 3 дня после отгрузки — если услугу проставят, он уйдёт из списка.

Доходы и расходы по месяцам

Отчёт о прибыли

Счета МПФИТ

Если клиент оплатил, а в МПФИТ счёт не отмечен — нажмите «Оплачен». Оплата запишется в журнал со ссылкой на счёт, в МПФИТ ничего не меняется.

Ожидаемая выручка

Не выставлено — отгрузки клиента после его последнего счёта, по его цене за отгрузку. Не оплачено — выставленные счета без оплаты.

Задать план

Пустое поле — план не задан. План по заказам делится на дни и рисуется пунктиром на графике заказов.

Постоянные платежи · расходы будущих периодов

Постоянный платёж начисляется в расходы каждого месяца пропорционально дням действия, независимо от даты оплаты. Сама оплата в журнале, привязанная к платежу, идёт только в движение денег — так аренда за квартал не «съест» прибыль одного месяца.

Журнал

Оплаты от клиентов пишутся для остатков по кассе и счёту, в выручку не идут — выручка берётся из счетов МПФИТ.
