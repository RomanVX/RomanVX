## Карточки, SEO, контент

- **Перенос карточек WB → Ozon** (`backend/routers/cardsync.py`, вкладка
  Ozon → «Карточки WB → Ozon»): сравнение фото по dHash (Хэмминг ≤10), загрузка
  фото пачками через pictures v2, описание → атрибут 4191. Название не трогаем
  (на Ozon своё SEO). Есть авторежим `loop()`.
- **SEO Ozon** (10.11): новые названия, аннотации, хештеги по таблице с
  комментариями владельца. Ключевые акценты: AL-01 — «гель для умывания» (не
  пенка); AL-05 — «сыворотка 50 мл»; смазки — «анал / анал и фистинг», чтобы не
  попадать в нецелевые запросы; спреи — «минет / спрей / лубрикант».
- **Rich-контент** сделан с `raTextBlock`, чтобы не затирать SEO-описание.
- **Склейки** «с логикой и под РК»: по группам выше, с учётом отзывов и
  рейтинга; наборы склеиваются с самым рейтинговым товаром из набора.
- **Декларации** для наборов Алоэ загружены через `/v2/product/certificate/create`.
- WB: наборы склеены с Алоэ (со сменой предмета), карточки NST-11 и наборов
  заведены в октябре.
