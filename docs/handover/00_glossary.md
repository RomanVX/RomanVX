# Словарь

## Сервисы и кабинеты

| Название | Что это |
|---|---|
| **wb-dashboard** | Дашборд кабинета **Biomed** (Biomed Nutrition): WB + Ozon + Яндекс Маркет. Render, тариф Starter (512 МБ). `DB_SCHEMA=biomed`. |
| **fk-dashboard** | Тот же код, кабинет **Миагра / «Фабрика красоты»** (WB + Ozon). Render free. `DB_SCHEMA=fk`. |
| **tl-dashboard** | Тот же код, кабинеты клиентов агентства **Технолюкс** (WB+Ozon) и **Аврора** (WB) — только чтение. |
| **mpfit-dashboard** | Отдельный сервис `mpfit_dash/` — фулфилмент: финансы ФФ, сотрудники, клиенты ФФ, «Упаковка КИЗ», ТСД. |
| **romanvx** | `wbfetch/` — небольшой Docker-сервис для запросов к WB. |
| **mp-postgres** | Одна база Postgres на Render для всех сервисов, кабинеты разведены по схемам. |
| **VPS в РФ** | Сервер в России: сайт `marketpartners.ru` + проход к дашбордам без VPN (Caddy + туннель Xray). |
| **WB-агент** | `agent/wb_browser_agent.py` — браузер на домашнем ПК владельца, собирает выдачу WB (серверные IP WB банит). |

## Бизнес

| Термин | Значение |
|---|---|
| **Market Partners** | Агентство Романа: ведение кабинетов селлеров (продвижение, аналитика, дашборд). |
| **ФФ / фулфилмент** | Склад Романа в Чехове: хранение, сборка FBS-заказов, упаковка, маркировка для клиентов-селлеров. |
| **МПФИТ** | Внешняя WMS/учётная система фулфилмента (mpfit.ru). У неё есть API, документация — `docs/mpfit_api/`. |
| **Клиенты ФФ** | Селлеры, чей товар хранится и отгружается со склада (напр. «Марципан», «Субоч» — твёрдые шампуни). |
| **Biomed** | Основной клиент агентства: интимная косметика (лубриканты Satisfucktion «ST-», «Джага-Джага»/BMN-, спреи Deep Throat) и косметика Алоэ (AL-). |
| **Миагра / «Фабрика красоты»** | Второй клиент: уход за лицом (сыворотки СР, кремы НКР), кремы для рук/тела (КР), мисты (ПС), очищение (ОМ), маски (МП), старая линейка шампуней/бальзамов (ШП/КБ/ГД). |

## Маркетплейсы

| Термин | Значение |
|---|---|
| FBO / FBW | Товар на складе маркетплейса. |
| FBS | Товар на нашем складе, маркетплейс забирает заказы (у нас — склад в Чехове через МПФИТ). |
| СПП | «Скидка постоянного покупателя» WB — скидка за счёт WB, цена покупателя ниже нашей. |
| ДРР | Доля рекламных расходов в выручке. |
| К выводу / payout | Сколько маркетплейс перечислит после комиссий, логистики, рекламы. |
| Юнитка | Юнит-экономика по артикулу (вкладка дашборда). |
| CPO / «Оплата за заказ» | Реклама Ozon с оплатой за заказ (фиксированная ставка 28% цены, 12% если товар ещё и в CPC). |
| CPC | Реклама Ozon за клики (кампании «Трафареты»/поиск с недельным бюджетом). |
| Репрайсер Ozon | Инструмент Ozon (`seller.ozon.ru/app/prices/repricer`), держит **одну цену для покупателя** сразу на Ozon и WB. API нет, только xlsx-шаблон. |
| КИЗ | Код маркировки «Честный знак» (DataMatrix): `01`+GTIN(14) `21`+серийный … |
| ТСД | Терминал сбора данных: Android-телефон со сканером. |
| Склейка | Объединение карточек в одну (вариации), на Ozon — атрибут 9048. |
| Rich-контент | Ozon, атрибут 11254 (JSON-блоки с картинками/текстом). |
