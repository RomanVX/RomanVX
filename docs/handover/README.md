## Важно про безопасность

- **Репозиторий публичный.** В документах нет токенов, паролей, PIN, секретных
  путей прокси, личных данных сотрудников и коммерческих условий договоров.
  Указаны только *названия* переменных окружения и где их менять.
- Все ключи живут в **Render → сервис → Environment** и в настройках дашбордов
  (ключи клиентов вводятся через интерфейс и хранятся в базе).
- Коммерческие условия (проценты вознаграждения, зарплатные ставки, реквизиты,
  контакты) владелец передаёт отдельно, не через GitHub.

## Как работал ассистент (чтобы продолжить в том же стиле)

- Код — в ветке разработки, потом пуш в `main`: Render сам деплоит все сервисы.
- Перед любым вызовом API маркетплейса — смотреть спецификацию в `docs/wb_api/`,
  `docs/ozon_api/`, `docs/mpfit_api/` (WB и Ozon часто отключают старые методы).
- Живые данные кабинетов ассистент брал через owner-only прокси дашборда
  (`POST /api/tools/mp/proxy`, см. `03_dashboard.md`) с cookie-сессией владельца.
- Изменения в кабинетах клиентов (цены, реклама, карточки) — только с согласия
  владельца. Технолюкс и Аврора — **только чтение**.
- Ответы на отзывы: пишутся вручную под каждый отзыв (или ИИ-черновики
  дашборда), публикуются через `/api/reviews/approve`.
