# МПФИТ — REST API

Официальная спека: `openapi.yaml` (скачана с https://app.mpfit.ru/openapi.yaml, версия 1.4.0).
Swagger UI: https://app.mpfit.ru/api-doc.html · справка: https://mpfit.ru/api/

- База: `https://app.mpfit.ru/api`
- Авторизация: `Authorization: Bearer <токен>`. Токен выдаёт поддержка МПФИТ.
  Токен компании-фулфилмента видит данные всех её селлеров.
- Лимит: 120 запросов в минуту на все методы (`X-RateLimit-Remaining`).
- Пагинация курсорная: `limit` + `last_id` (первый запрос `last_id: 0`).

Методы: каталог (список, создание, штрихкоды, категории), остатки
`/v1/products/stocks`, приёмки `/v1/arrivals/*`, отгрузки `/v1/orders/*`,
компании и баланс, счета, аналитика хранения, использованные КИЗы `/v1/cim-codes`.

Чего в API нет: настроек и журнала передачи остатков на маркетплейсы
(проценты по складам WB, время последней синхронизации) — только через интерфейс.
