# МПФИТ (mpfit.ru) — полная выжимка по платформе

> Конспект-справочник по WMS МПФИТ, собранный из официальной справки (help.mpfit.ru,
> mpfit.ru/help), продуктовых страниц и тарифов. Дата сбора: 2026-08-28.
> Мы работаем в МПФИТ ежедневно (фулфилмент в Чехове, см. `docs/wms_spec.md` — там МПФИТ
> используется и как индустриальный референс для собственной WMS).

## 1. Что это

**МПФИТ — облачная WMS для фулфилментов, селлеров и любых складов.** Принцип: один раз
настраиваешь правила — система применяет их к каждой заявке автоматически, от приёмки до
отгрузки. Единый сток на все каналы продаж.

Факты о платформе:
- Через систему проходит ~12 млн единиц товара/мес на 200+ складах и фулфилментах.
- В Реестре российского ПО Минцифры; авторизованный сервис Wildberries и Ozon.
- 30+ интеграций: WB, Ozon, Яндекс Маркет, МегаМаркет, Лемана Про (Leroy), Uzum, Kaspi,
  Avito, Tilda, InSales, соцсети, 1С. Открытый REST API.
- Пользователи не тарифицируются (платят за обработанные товары), число ролей — от 3 до
  безлимита в зависимости от тарифа.
- Внедрение — «за один день». Онбординг: 4 бесплатных созвона до 60 минут; после внедрения
  поддержка платная (созвоны и тикеты).

- **Товары** → Добавить товар · Управление товарами (Экспорт / Импорт Excel / Обновление

  Этикетки (конструктор).
- **Склад** → Заявка на приемку · Заявка на отгрузку · **Обработка** (все новые FBS/FBO-заказы)
  · **Отгрузка** · **Размещение** (назначение ячеек) · **Контроль** (проблемные/проверяемые
  заказы) · Ячейки · График работы.
- **Заявки** → Приёмки · **Отгрузки** (все созданные заявки, там же архив/отмена заказов).
- **Компании** → Список компаний → компания → вкладка **«Маркетплейсы»** (подключения API,
  вкладки «Настройки API» и «Каталог» с блоком «Синхронизация»).
- **Настройки** → Склад → Отгрузки (правила дат/поставок) · Комплектация (направления
  отгрузки) и пр.

Ключевые сущности: **Компания** (клиент фулфилмента / кабинет селлера) → у компании
подключения к МП; **Мастер-каталог** — внутренние карточки, к которым привязываются товары
маркетплейсов (**связки**); **смарт-товар** — набор/комплект; **внутренний заказ** — задание
на сборку набора; **услуги** и **расходники** — биллинг фулфилмента; **КИЗ** — коды Честного
знака.

## 4. Подключение маркетплейсов

Общий путь: Компании → Список компаний → компания → «Маркетплейсы» → «+» под нужным МП →
вкладка «Настройки API».

### Wildberries (help.mpfit.ru/connect_wb_api)
1. Токен создаётся в ЛК WB. **НЕ ставить галочку «Только для чтения»** — иначе тумблеры
   управления в МПФИТ не включатся (главный симптом read-only токена).
2. Выбрать склад (создаётся в ЛК WB). Для FBO склад указывать не нужно.
3. После синхронизации каталога и внесения остатков включить:
   **«Управление остатками»** (остатки МПФИТ → МП) и **«Управление заказами»** (заказы МП → МПФИТ).

### Ozon (help.mpfit.ru/connect_ozon_api)
1. ЛК Ozon: Настройки → API-ключи → Сгенерировать. Тип: «Администратор» (ADMIN) либо
   Product + Posting FBS + Warehouse — каждый **без** read-only. Скопировать Client ID + API Key.
2. Вставить в МПФИТ → Сохранить → указать склад → галочки управления остатками/заказами.
3. ⚠️ **Перед включением управления остатками убедиться, что в МПФИТ корректные остатки —
   иначе система отправит на Ozon НУЛИ** (товар «пропадёт» с витрины).

### Яндекс Маркет (help.mpfit.ru/yandex_market_api_setup)
Компании → столбец «Яндекс Маркет» → «+». Создать API-токен в ЛК ЯМ (параметры по образцу из
статьи), вставить — при успехе зелёная плашка. Товары сами подтянутся во вкладку «Каталог»;
если карточки уже есть с других МП — «Синхронизация» → «Обновить» (автосвязка по баркодам).
Товар только на ЯМ → значок «Скрепка» → «Создать товар в каталоге».
⚠️ Этикетки ЯМ **не грузятся автоматически** — только вручную из ЛК маркетплейса.

### МегаМаркет (help.mpfit.ru/megamarket_api_setup)
Каталог: скачать файл в ЛК ММ (partner.sbermegamarket.ru/main/catalog/matched) → загрузить в
МПФИТ (настройки ММ → вкладка «Каталог»). Обмен: блоки 1–2 копируются из МПФИТ в ММ, пункт 3 —
из ММ в МПФИТ → Сохранить. В ММ включить галочку «Интеграция» (не включается — писать в
поддержку ММ). Затем связать каталоги.

## 5. Связка товаров между маркетплейсами (Ozon ↔ WB)

Источник: help.mpfit.ru/link_identical_products
(= mpfit.ru/help/rabota-s-tovarami/kak-svyazat-tovary-mezhdu-ozon-i-wildberries/).

Зачем: один товар на разных МП должен быть одной сущностью — тогда остатки/заказы считаются
корректно и товары не дублируются (основа «единого стока»).

**Механика связки — совпадающий баркод.** Пошагово (массовый способ):
1. Товары → Управление товарами → раздел **«Экспорт»** → фильтр (компания / бренд / категория /
   смарт-товары / всё) → **«Скачать XLS»**.
2. В Excel прописать **баркоды второго маркетплейса** в соответствующие строки.
   Баркоды одинаковых товаров на разных МП должны **совпадать**.
3. Загрузить файл обратно: раздел **«Обновление товаров»** → тот же Excel → «Обновить».
4. Компании → Список компаний → компания → «Маркетплейсы» → «Каталог» → блок
   **«Синхронизация»**, подраздел баркодов → **«Обновить» ровно 1 раз**, дождаться загрузки.
5. После обновления баркодов в подразделе «Добавить товар во внутренний каталог» нажать 1 раз
   «Обновить» — через ~5 минут несвязанные товары появятся в каталоге МПФИТ.

⚠️ **Если каталог одного МП уже загружен — НЕ нажимать кнопки синхронизации у второго МП.**
Связка делается один раз; повторные нажатия плодят дубли.

Точечная альтернатива: Товары → Мастер-каталог → найти карточку → «Редактировать» → вписать
баркод нового МП вручную.

## 6. Работа с товарами

- Добавить один товар: Товары → «Добавить товар» → обязательные поля → «Добавить».
- Массово: Управление товарами → «Импорт товаров Excel-файлом» (шаблон).
- Экспорт: Управление товарами → «Экспорт» (фильтры, «Скачать XLS»).
- Новые карточки с МП через API: Компании → компания → Маркетплейсы → МП → «Каталог» →
  Фильтр «Привязка к мастер-каталогу» = «Нет» → Применить → «Обновить» в блоке
  «Добавить/обновить товары». Займёт 10–30 минут (help.mpfit.ru/sellers_new_items).
- «Код товара» — внутренний идентификатор МПФИТ, нужен для загрузок файлами
  (help.mpfit.ru/product_code).
- **Смарт-товары (наборы):** создаются в каталоге (поштучно или массово Excel), в «Связках»
  привязываются к товару МП. Если на момент заказа готового набора нет — МПФИТ создаёт
  **внутренний заказ** на сборку; после его выполнения обрабатывается заказ клиента.
  Акты и накладные — в один клик.

## 7. FBS: полный цикл заказа

1. **Заказы приходят сами**: все новые заказы (FBS и FBO) с WB/Ozon/ЯМ падают в
   Склад → **«Обработка»** в момент оформления (API). Остатки уходят на МП после каждой
   складской операции, долетают ~за 1 минуту.
2. **Фильтры**: номер заказа, компания, артикул, штрихкод, дата отгрузки; плюс три фильтра
   сборки «По Компании / По типу заказа / По артикулу».
3. **Сборка**: «Принять заказ» с ТСД/смартфона/ПК. Массово по одинаковым артикулам:
   Тип + Артикул → **«Принять все» → «Собрать все»** → лента этикеток на одинаковый товар
   одним кликом (help.mpfit.ru/collect_identical_orders).
4. **Умная лента** (help.mpfit.ru/smart_tape): массовая приёмка и сборка FBS-заказов **разных**
   SKU с печатью всех этикеток разом. Порядок печати: общая этикетка сборки → этикетка SKU
   с местом хранения → лента этикеток МП этого SKU → следующий SKU.
5. **Этикетки**: WB и Ozon — автоматически из МП (сборщик печатает прямо из задания, без
   скачивания файлов из ЛК). ЯМ — вручную. МПФИТ этикетки FBS не модифицирует — содержимое
   приходит от МП как есть.
6. **Контроль**: заказы, у которых этикетка МП не успела загрузиться (принят и собран, а
   этикетки нет), падают в Склад → «Контроль». Дождаться загрузки → распечатать → в отгрузку.
   Там же — проверка собранного заказа отдельным сотрудником (не сборщиком).
7. **Отгрузка**: после «Принять все → Собрать все» заказы уходят в Склад → «Отгрузка», система
   выводит на печать все этикетки собранного.
8. **Отмена заказа «готов к отгрузке»** (help.mpfit.ru/cancel_ready_for_shipment):
   Заявки → Отгрузки → открыть заказ → «В архив». ⚠️ **Бронь с товаров сама НЕ снимется**:
   дальше в «Контроле» у заказа появится «не отгружать — заказ отменен» → «отгрузить —
   отправить в отгрузку» → в «Отгрузке» «отметить — отгрузить» → товар вернётся в
   «Размещение» → назначить ячейку → «Сохранить» → товар снова на остатках.

### Поставки Wildberries FBS (help.mpfit.ru/deliveries_of_wildberries_fbs)
- Настройки → Склад → Отгрузки. **«Правило установки даты отгрузки»** — WB сам дату не задаёт,
  МПФИТ подставляет свою «отсечку» складу: машина уезжает в 11:00 → ставим 10:00; заказы до
  10:00 = «сегодня», после 10:01 = «завтра».
- **Поставки WB создаются и закрываются автоматически** (нужно включённое «Управление
  заказами»). Вручную в ЛК WB ничего открывать/закрывать не надо. Параметр «сколько раз в
  сутки» управляет тем, докидывать ли заказы в существующую поставку или создавать новую.
- Календарь отгрузок держит дедлайны WB на виду у склада.

### FBO
Поддерживается комплектация FBO-поставок (WB): печать ШК коробов (одного или всех), после
наполнения коробов — скачать файл с коробами для загрузки в поставку в ЛК.
Обработка FBO-заказа: help.mpfit.ru/fbo_order_processing. Заказы FBO тоже видны в «Обработке».

### Отключение FBS (mpfit.ru/help/dopolnitelnye-moduli/kak-otklyuchit-rabotu-po-fbs/)
Компании → компания/МП → Настройки API → блок «Управление» → выключить **оба** ползунка.
⚠️ Предупредить свой фулфилмент до отключения/включения.

## 8. Склад: приёмка, ячейки, размещение, инвентаризация

### Заявка на приёмку (селлер: help.mpfit.ru/application_admission)
Склад → «Заявка на приемку» → ожидаемая дата прихода → компания → товары **вручную** (мало)
или **Excel-шаблоном** (много) → количества → «Создать». При создании можно заказать **забор
товара** (если нечем довезти до склада).

### Приёмка с ТСД (help.mpfit.ru/tsd-acceptance)
ТСД → «Приемка» → скан товара → откроется нужная приёмка → скан штучно или ручной ввод
количества. Товар без ШК: двойной тап → печать этикетки из мастер-каталога или **временный
ШК**. Всё пересчитано → «Принять» → «Отправить» → товар уходит в **«Размещение»** (назначение
ячеек). Есть видео-инструкции.

### Ячейки и адресное хранение (help.mpfit.ru/creating_storage_bins, warehouse_marking)
- Склад → «Ячейки». Создание: массово Excel («Скачать шаблон» — если ячеек ещё нет;
  «Выгрузить ячейки» — если добавляем к существующим) или поштучно «+».
- Формат адреса: `[латиница ≤2 симв верхним регистром]-[0–99]-[0–99]`.
  `A-1-1` = полка, `AA-1-1` = паллетное хранение.
- Печать этикетки (ШК) ячейки: Склад → Ячейки (help.mpfit.ru/cell_barcode_printing).
- Хранение: статическое (товар закреплён за ячейкой), динамическое (в свободную подходящую)
  или комбинация (ходовым — постоянные места). Система сама предлагает ячейку под размещение
  и отбор; ячейки помечаются свободные/занятые.
- Внедрение адресного хранения — без остановки склада: новые приёмки сразу по адресам, старый
  остаток переводится по ходу работы или разовой инвентаризацией.
- Перемещения: есть инструкции «изменить ячейку/переместить товар» (ТСД и браузерная версия),
  «назначить ячейки хранения всем товарам».

### Сборка по ячейкам («Подбор»)
Группирует заказы по ячейкам: сборщик получает задание на ТСД, система ведёт по ячейкам в
приоритетном порядке, требует скан адреса ячейки и товара (защита от ошибок). Новичок собирает
с первого дня — маршрут и проверка зашиты в приложение.

### Инвентаризация
Через ТСД или сканер, **без остановки склада**, по зонам и циклам. Поддерживаются партии,
сроки годности (FEFO/FIFO), серийные номера, возвраты и брак; полная история операций с
привязкой к сотруднику.

### График работы и выработка
Склад → «График работы»: смены сотрудников включаются/выключаются тумблером
(help.mpfit.ru/working_hours). Каждый сотрудник работает под своим логином, выработка
фиксируется в реальном времени — система сама считает, **сколько выставить клиенту и сколько
заплатить сборщику** (сдельная оплата).

### Возвраты
Возвраты разных селлеров приходят на склад общей поставкой — система помогает разобрать по
компаниям. Реальная прибыль по позиции считается с учётом затрат и возвратов. Для
маркированных возвратов см. «освобождение КИЗов» ниже.

## 9. Честный знак / КИЗы (help.mpfit.ru/marking)

- В карточке товара (Товары → Мастер-каталог) должно стоять «КИЗ/акциз — да»; кнопка «КИЗ».
- Загрузка кодов: товар уже маркирован → «Сканировать» (КИЗы + номер приёмки в базу);
  коды пришли файлом → «Добавить из базы» → печать нужного количества.
- При приёмке: указать фактическое количество → кнопка «КИЗ».
- Статусы: при печати КИЗ получает номер и дату заказа/отгрузки → «занят»; свободные — без
  даты/номера. Занятые повторно в печать/работу не берутся.
- **При сборке КИЗ сверяется с заказом: чужой, битый или повторный код система не пропустит.**
- «Освобождение кодов» — для перепечатки, возвратов, порчи упаковки/товара.
- Бесплатный онлайн-дубликатор КИЗ: mpfit.ru/tools/dublirovanie-chestnogo-znaka.
- Для сканирования маркировки подходит любой бюджетный 2D-сканер, читающий DataMatrix.

## 10. Этикетки

- **Конструктор этикеток 3.0** (help.mpfit.ru/label_designer): Товары → Этикетки →
  «+ Добавить шаблон» → название/описание → формат бумаги (стандарт **58×40**) → выбрать поля
  и формат отображения → предпросмотр → Сохранить. Доступен во всех тарифах.
- **Ozon FBS 58×40** (help.mpfit.ru/ozone_fbs_label_size): если печатается 120×75 — сменить в
  ЛК Ozon: FBS → Управление логистикой → у склада «⋮» у метода доставки → «Редактировать
  метод» → включить «Печатать этикетку 58×40».
- Отключение печати этикетки товара в WB FBS — есть отдельная инструкция (см. all_instruction).

## 11. Биллинг фулфилмента (услуги, расходники, хранение)

- **Услуги**: добавляются в заявку (к позициям или ко всей заявке) кнопкой «+» → галочка;
  количество указываешь — стоимость подставляется из прайса автоматически. Редактируются на
  любом этапе. **Счета, УПД и акты собираются автоматически из выполненных заявок.**
- **Прайс**: у фулфилмента свой прайс-лист услуг; цены задаются интервалами от количества
  (если цена фиксированная — одинаковая во всех интервалах).
- **Расходники** (help.mpfit.ru/consumables_accounting): учитываются расходники фулфилмента
  (не клиентов). Карточка на компанию фулфилмента: тип «упаковка (штучная)», код товара
  (нужен для приёмки файлом), артикул. Принимаются на остатки как обычный товар
  (заявка на приёмку → приёмка → размещение). Услуга с расходником: пока заявка не выполнена —
  бронь остатка; выполнена — списание сразу.
- **Хранение** (help.mpfit.ru/storage_accounting): цена за 1 м³; учёт «по объёму товара» или
  «по объёму ячейки» (задаётся на ячейке). Раздельно свободный объём (лежит) и
  зарезервированный (собирается, не отгружен). Система ежедневно генерирует операцию хранения
  по каждому клиенту → один счёт за весь период, с разбивкой объёма по дням.
- **ЛК клиента**: клиент фулфилмента видит свои заявки, историю и статусы заказов, остатки;
  создаёт заявки на приёмку/отгрузку сам; доступы сотрудникам селлера —
  help.mpfit.ru/access_client_employees. Подтверждение оферты фулфилмента клиентом —
  help.mpfit.ru/confirmation_of_the_offer.
- **Уведомления**: о новых заказах и отгрузках — на почту и в Telegram (инструкция «Как
  настроить уведомления»).

## 12. Оборудование и ТСД

- Минимальный набор: принтер этикеток + ТСД или Android-смартфон + ПК/планшет (браузер:
  Chrome/Яндекс/Firefox/Safari).
- **Печать настраивается только на Windows**; с iOS можно печатать, если в профиле указано
  рабочее место с настроенным Windows-ПК. Настройку принтера делает разработчик МПФИТ удалённо
  (написать менеджеру, поставить AnyDesk).
- Принтеры (термо): TSPL — Xprinter, TSC, АТОЛ; ZPL — Zebra, Honeywell; 203/300 dpi.
  Проверенные модели: Godex G300, IDPRT SP420, MPRINT Terra Nova TLP300, Pantum PT-D160,
  Proton TTP-4206, Rongta RP4xx, TSC DA210.
- ТСД: Newland MT65 Beluga IV, Atol Smart Slim / Lite / PRO, Urovo TD-40 — или любой
  Android-смартфон (нативное приложение, освоение ~час). Аренда ТСД у МПФИТ: 3 000 ₽/мес
  (в базовых пакетах 2 ТСД включены).
- Установка apk на ТСД (help.mpfit.ru/setting_pdt): если не качается — перекинуть apk кабелем
  с ПК и поставить из файлового менеджера. Настройка сканера: приложение Barcode Setting →
  General Settings → «Send scanning via» → **Broadcast** (⚠️ другие приложения на ТСД
  перестанут получать сканы, пока не вернёшь KEYBOARD_EVENT). Не помогает — переустановить
  приложение МПФИТ.

## 13. Тарифы и оферта (на 2026-08)

- Модель: **pay-per-use, тарификация по обработанным товарам**; пользователи бесплатны.
  Годовая оплата — скидка 20%.
- «Конструктор» — от 4 990 ₽/мес. «Соло» (селлер WB) — 9 990 ₽/мес до 3 000 отгруженных
  товаров. Для фулфилмента — от 24 990 ₽/мес.
- «Старт» — до 10 000 товаров/мес; расширения: +25 000 товаров = 12 500 ₽, безлимит = 25 000 ₽.
  «Бизнес» — до 30 000 товаров/мес (+аналогичные расширения).
- В тарифы входит: FBO+FBS, наборы/комплекты, КИЗы, конструктор этикеток, ЛК клиента, прайс,
  счета/документы, свой логотип, Telegram-уведомления.
- Private Label (свой домен) — 20 000 ₽/мес.
- Оферта (mpfit.ru/oferta): лицензионный договор; **первый месяц — пробная лицензия с правом
  возврата денег**; территория — РФ и СНГ.

## 14. REST API

- Справочник: https://app.mpfit.ru/api-doc.html (методы, параметры, авторизация);
  обзор — https://mpfit.ru/api/ и help.mpfit.ru/api-key.
- **API-ключ МПФИТ выдаётся по запросу в Telegram-чате МПФИТ** (у менеджера).

## 15. Грабли — сводный чек-лист

1. Токен WB с галочкой «только чтение» → тумблеры управления не включаются. Перевыпустить.
2. Включили «Управление остатками» Ozon до внесения остатков в МПФИТ → **на Ozon уедут нули**.
3. Синхронизацию баркодов при связке жать **один раз** и только у одного МП; у второго — нет.
4. Отмена заказа «готов к отгрузке» через «В архив» **не снимает бронь** — обязательно прогнать
   через Контроль → Отгрузка → Размещение (иначе остаток «завис»).
5. Этикетки ЯМ не подтягиваются сами — вручную из ЛК ЯМ.
6. Заказ «завис» без этикетки → он в разделе «Контроль», ждать подгрузки этикетки, не терять.
7. Печать — только через Windows-машину; настройка принтера — через менеджера + AnyDesk.
8. Broadcast-режим сканера на ТСД ломает скан в других приложениях (KEYBOARD_EVENT обратно).
9. Перед выключением/включением FBS-тумблеров — предупредить фулфилмент.
10. «Кнопки нет» при создании отгрузки = товара нет на остатках.
11. Поставки WB не трогать руками в ЛК — МПФИТ открывает/закрывает их сам.
12. Дата отгрузки WB FBS — это «отсечка» МПФИТ (ставить на час раньше реального выезда машины).

## 17. Связь с нашим WMS-проектом (`docs/wms_spec.md`)

МПФИТ — рабочая система нашего фулфилмента и одновременно референс для собственной WMS.
Паттерны МПФИТ, уже отражённые в спеке: ТСД = Android-смартфон; приёмка только по заявке;
адресные ячейки со сканом подтверждения; биллинг-события из операций (счета/УПД из выполненных
заявок); ежедневная операция хранения по объёму; контроль отдельным сотрудником; сдельная
выработка сборщиков. Отличия нашей спеки: партионный учёт со сроками — обязателен на приёмке,
прогрессивное хранение по возрасту партии, append-only журнал операций.

> Примечание о происхождении: конспект собран поисковой выгрузкой официальной справки
> (прямой доступ к mpfit.ru из этой среды закрыт сетевой политикой). Формулировки шагов
> сверены по нескольким запросам; при расхождении с интерфейсом верить продукту и статье.
