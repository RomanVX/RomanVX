# Корональные дыры (SDO/AIA 211Å) × курс биткоина

Автономный исследовательский инструмент: проверяет корреляцию между
относительной площадью корональных дыр по данным SDO/AIA 211Å (модель
квазистационарного солнечного ветра НИИЯФ МГУ, swx.sinp.msu.ru) и курсом
BTC/USD — «в грамотных разрезах», с честной статистикой и несколькими
способами экстраполяции.

> **Изоляция.** Каталог `research/btc_ch211/` полностью автономен: не
> импортирует и не трогает ничего из `backend/`/`frontend/` (инструменты
> маркетплейса) и никак с ними не связан.

## Запуск

```bash
cd research/btc_ch211
pip install -r requirements.txt
python run.py            # → out/fig1…fig7.png, out/REPORT.md
```

## Что делает пайплайн («инструмент обнаружения»)

1. **Лаг-скан** r(k) для k = −12…+12 дней (k>0 — Солнце раньше BTC): уровни
   (z-нормировка внутри окна), сглаженные уровни MA(3), приращения
   (ΔCH × лог-доходность) — по каждому непрерывному окну данных и по пулу.
2. **Честные нули**:
   - эффективный N по Бартлетту (автокорреляция съедает степени свободы);
   - **циркулярные суррогаты**: у ряда CH сохраняется вся автокорреляция, но
     случайным циклическим сдвигом разрушается выравнивание с BTC; повторяя
     3000 раз, получаем распределение max|r| по всему скану — то есть p-value
     с учётом того, что лаг мы *подбирали*;
   - блочный бутстрэп для CI коэффициента;
   - отдельный суррогатный тест для «вау-цифры» каждого окна.
3. **Стабильность знака**: скользящая корреляция — у настоящей связи знак
   держится, у совпадения гуляет.
4. **Событийный разрез**: пики/впадины площади CH → средний путь BTC ±8 дней.
5. **Позитивный контроль**: тот же лаг-скан на паре «CH × фактическая скорость
   солнечного ветра» — физически связанной. Инструмент обязан находить (и
   находит) её на лаге +2…+4 дня; это проверка, что методика вообще способна
   ловить настоящие запаздывающие связи.
6. **Разрез «с растяжением времени»** — формализация наложения «N дней СДО на
   месяцы рынка» (TradingView-оверлей): перебор масштабов ×0.25…×55 и всех
   сдвигов куска солнечного ряда против того же перебора на случайно
   прокрученном ряде. Показывает, что растяжение — генератор гарантированных
   совпадений: случайный ряд добивается |r|≈0.9 в половине попыток.
7. **Допрос пограничных сигналов**: детренд (минус скользящее среднее 27 дн),
   воспроизводимость в половинах периода, «синусоида-двойник» вместо Солнца.
8. **Решающий прогнозный тест (walk-forward)**: каждый день модель обучается
   только на прошлом и предсказывает завтрашнюю доходность; SOLAR (только
   солнечные признаки) против AR (только прошлые цены) и ZERO («завтра как
   сегодня») — hit-rate направления с биномиальным p, skill по MSE,
   игрушечные знаковые стратегии.
9. **Экстраполяции «по-разному»**: площадь CH — гармоника кэррингтоновского
   периода 27.27 дн (вся история и последнее окно), демпфированный Holt,
   AR(2); BTC — веер лаг-модели btc_ret(t)=a+b·ΔCH(t−k*) с бутстрэпом остатков
   против бейзлайнов RW-с-дрейфом и AR(2).

Результаты текущего прогона — **`out/REPORT.md`** (перегенерируется при каждом
запуске).

## Итог на данных 08.08.2025–05.07.2026 (317 дневных пар, биржевые цены)

| проверка | результат |
|---|---|
| уровни, лучший лаг по пулу | r=+0.26 (k=+10), p(скана)≈0.07 — **на грани**, поэтому допрошен отдельно ↓ |
| допрос: детренд (минус MA 27 дн) | r падает до +0.19, p≈0.67 — сходство несут медленные волны |
| допрос: половины года порознь | +0.18 и +0.21 — знак стабилен, но обе цифры объяснимы случайностью |
| допрос: синусоида 27.27 дн вместо Солнца | r=0.06 — сходство не сводится к чистому ритму |
| **решающий тест: walk-forward прогноз** | SOLAR угадывает направление 51.5% (монетка, p=0.76), skill<0; AR без Солнца 54.4% (p=0.28) — **предсказательной силы нет** |
| приращения, лучший лаг | r=+0.09, p(скана)≈0.95 — шум |
| 4-часовые бары | те же r=+0.26 и k≈+10 дн, N=1696, но N_eff≈75 — новых знаний нарезка не даёт |
| растяжение времени ×0.25…×55 | лучшее r=+0.91, но случайный ряд даёт то же в ~50% попыток — p≈0.81 |
| позитивный контроль CH×СВ (год) | r=+0.31 (k=+3), p≈0.048 — учебный лаг долёта потока; инструмент рабочий |

**Вердикт: сходство форм на графиках реально, но его несут медленные волны
конкретного года; в честном прогнозном тесте солнечные данные не дают ничего —
строить торговую логику от Солнца на этих данных нельзя.** Пайплайн готов к
пополнению данных: обновите файлы в `data/` и перезапустите.

## Откуда берётся «видимая» корреляция

1. **Свобода наложения.** Двойная шкала графика позволяет произвольно
   растягивать и сдвигать ряд по вертикали (а часто и по времени) — почти
   любые два гладких ряда можно «совместить» на выбранном участке.
2. **Автокорреляция.** Оба ряда гладкие, поэтому случайные совпадения тянутся
   днями и выглядят системными. Наши суррогаты показывают: чистая случайность
   с такой же автокорреляцией даёт |r| до ~0.5 по пулу и ~0.8 в коротком окне.
3. **Перебор степеней свободы.** Выбор лага (25 вариантов), окна, сглаживания,
   масштаба — множественные сравнения: «наивный» p≈0.04 превращается в честный
   p≈0.6.
4. **Медленные волны.** Оба ряда за год прошли по несколько многомесячных
   «горбов»; таких волн мало, и вероятность, что часть из них совпадёт по
   фазе, велика. Тест с детрендом это и показывает: сходство почти целиком
   живёт в медленной составляющей.
5. **Есть ли физический канал в принципе?** Цепочка «CH → быстрый поток СВ
   (+2…4 дня; наш контроль это видит) → геомагнитная активность → настроение
   людей → рынки» обсуждалась в литературе (Krivelyova & Robotti, 2003, про
   геомагнитные бури и биржевые доходности); последующие проверки дают слабые
   и нестабильные эффекты — доли процента на десятилетиях данных. То есть
   канал не запрещён физикой, но если он есть, он на порядки слабее того, что
   кажется по наложенным графикам.

## Как правильно искать такую связь (чек-лист)

1. Сформулировать гипотезу **до** подгонки: знак, лаг, масштаб (например,
   «рост площади CH предвещает падение BTC через 3–5 дней»).
2. Считать на **приращениях/доходностях**, не на уровнях.
3. Любой перебор (лаги, окна, сглаживания) оплачивать суррогатным
   max-статистик-тестом или поправкой на множественность.
4. Требовать **воспроизводимости знака** в непересекающихся окнах.
5. Держать **позитивный контроль** (CH×СВ) — иначе не отличить «связи нет» от
   «инструмент слеп».
6. Финальный судья — **вневыборочный тест**: модель фиксируется на истории и
   проверяется на новых данных.
