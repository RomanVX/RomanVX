# Данные: происхождение и как их заменить на точные

## Что лежит здесь сейчас (и почему это «оцифровка», а не выгрузка)

Сессия работает в окружении с закрытой сетью: наружу доступны только пакетные
реестры и поисковые сниппеты, сайт `swx.sinp.msu.ru` и биржевые API недоступны
(403 на уровне прокси). Поэтому текущие файлы — **ручная оцифровка скриншотов
пользователя** с перекрёстной калибровкой по датированным ценовым фактам из
поисковой выдачи.

### `ch211_daily.csv`
Дневные средние «CH relative corrected area (by SDO 211A) [%]» с сайта
Центра прогнозов космической погоды НИИЯФ МГУ (swx.sinp.msu.ru), сняты с двух
скриншотов графика:

| окно | период | точек | погрешность чтения |
|------|--------|-------|--------------------|
| `apr` | 2026-04-07 … 2026-04-19 | 13 | ±0.5–0.7 п.п. |
| `jun` | 2026-06-12 … 2026-07-05 | 24 | ±0.8–1.0 п.п. |

Колонки: `date, ch211_pct, sigma_pct, window, source`.

### `btc_usd_daily.csv`
Дневные закрытия BTC/USD, март — июль 2026. Основа — оцифровка дневных свечей
со скриншота TradingView (шкала 44–88k, ±$700–1200), пришпиленная к датированным
якорям из поиска:

* 2026-04-05 — пробой $70k (новостные сводки апрельского ралли)
* 2026-04-13 — «cleared $74,000»
* 2026-05-06 — $82,305.01 (Yahoo Finance, утро, «highest since Jan 31»)
* 2026-05-29 — $73,105.71 (Fortune)
* 2026-06-06 — интрадей-минимум ≈$61,100 (тест 200-недельной MA)
* 2026-06-10 — CPI-день, минимум ≈$61,500
* 2026-06-24/25 — ночной минимум $59,023 (ликвидации ~$1B)
* 2026-06-30 — $58,503.73 (Fortune, 9:15 ET)
* 2026-07-05 — $62,883.77
* 2026-07-06 — 63,775 (тег с графика, неполный день — в анализе не используется)

Колонки: `date, close_usd, sigma_usd, provenance` (`anchor:*` — датированный
факт, `digitized` — чтение свечи).

**Погрешность такой оцифровки (±1–2%) на порядок меньше амплитуды исследуемых
движений (±10–30%)**, поэтому для разведочного анализа она пригодна; для
финального вывода замените файлы на точные выгрузки — пайплайн подхватит их
автоматически.

## Как заменить на точные данные (5 минут)

### 1. Площадь корональных дыр (SINP)
На странице https://swx.sinp.msu.ru/models/solar_wind.php?gcm=1 у графика
справа внизу есть меню **≡ → Download CSV** (стандартный экспорт Highcharts).
Выберите нужный диапазон дат стрелками/календарём, скачайте и положите файл как:

```
research/btc_ch211/data/sinp_export.csv
```

Загрузчик сам найдёт колонку, содержащую `211`, распарсит DateTime и усреднит
до дневных значений. Чем длиннее диапазон — тем лучше (лаг-скан и суррогатные
тесты становятся осмысленными от ~6 месяцев, т.е. ~7 кэррингтоновских оборотов).

### 2. Курс BTC
Любой дневной CSV: экспорт Binance/Bybit (`open_time,open,high,low,close,...`),
investing.com («"Jul 05, 2026","62,883.8",…»), CoinMarketCap, Yahoo. Положите как:

```
research/btc_ch211/data/btc_export.csv
```

Загрузчик распознаёт колонки дат (`date/time/open_time/Дата`) и цены закрытия
(`close/price/Цена`), включая кавычки/разделители тысяч/запятую как десятичный
знак.

### 3. Перезапуск
```
cd research/btc_ch211
pip install -r requirements.txt
python run.py
```
Если `sinp_export.csv`/`btc_export.csv` присутствуют — используются они,
иначе — оцифрованные файлы выше. Отчёт и графики перегенерируются в `out/`.
